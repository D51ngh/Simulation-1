One X stabilizer measures four data qubits (Q1 top, Q2 right, Q3 bottom, Q4 left). Set the noise and circuit timing, then run a single shot or collect statistics over many shots.

Model

  • Chain: fluctuation δω(t) → H(t) = ħδω(t)Z/2 → U = e−iθZ/2 with θ = ∫δω dt (exact for this Hamiltonian, 1 ns steps) → Z error with P = sin²(θ/2) → syndrome → detection event. No decoder is applied in the Lab.
  • Each qubit is sampled at the end of its CNOT; phase accumulated afterwards counts toward the next round.
  • At the end of readout, the sampled phase θ becomes a Z error with probability sin²(θ/2) and is then reset.
  • The syndrome is the parity of the four qubits, so two errors in the same round cancel.
  • OU noise is generated with unit stationary variance and scaled by the peak shift, so Var(δω) is the same for every τc.
  • A detection event is a change in the syndrome. Latency is measured from noise onset to arrival of the first detection result.
  • Data qubits are treated independently; this gives correct detection timing but omits the entangled code state and correlated multi-qubit dynamics. Not included: the multilevel transmon Hamiltonian, gate pulses, T₁/T₂, gate and measurement errors.
