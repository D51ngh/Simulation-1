From phase noise to error correction

This project studies how phase noise on a transmon qubit is detected by stabilizer measurements, and how long detection takes. The seven steps below build the model one piece at a time, each with an interactive simulation.

Step 1

Qubit phase and phase error

A qubit state is drawn as an arrow on the Bloch sphere. |0⟩ and |1⟩ are the poles. |+⟩ and |−⟩ lie on the equator. We prepare the qubit in |+⟩ and call it fine; |−⟩ is flipped.

A transmon has a known frequency, so its arrow rotates steadily around the equator. This rotation is expected and is not an error. Environmental noise shifts the frequency by a small amount δω, so the qubit rotates slightly too fast or too slow. The resulting angle between where the qubit should be and where it is, is the phase error θ:

θ = ∫ δω(t) dt

We describe the qubit in the rotating frame, which follows the expected rotation. In this frame the correct arrow is fixed and only the error moves.

Model scope: the noise enters only through the frequency shift δω, giving the two-level Hamiltonian H(t) = ħδω(t)Z/2, whose evolution is exactly U = e−iθZ/2. The full multilevel transmon Hamiltonian is not simulated on this site (see Step 7).

Noise model

We model δω as an Ornstein–Uhlenbeck (OU) process, random noise with a finite memory. It has two parameters: the correlation time τc (how long the noise stays correlated with itself) and the variance V (its strength). We hold V fixed and vary τc (σ = √(2V/τc)), so that changes in the results come from the noise memory alone.

Key point: a frequency error, accumulated over time, rotates the qubit away from its expected state by a phase error θ.
Step 2

A phase error is a superposition of "fine" and "flipped"

A qubit rotated by θ can be written exactly as a combination of |+⟩ and |−⟩:

|ψ⟩ = cos(θ/2) |+⟩ − i sin(θ/2) |−⟩

A measurement in this basis returns "fine" with probability cos²(θ/2) and "flipped" with probability sin²(θ/2). A 180° phase rotation, or π-rotation about the Z axis, produces a certain Z error (phase flip).

Step 3

One stabilizer round

The data qubit is not measured directly. An ancilla qubit performs the check. One check is a round:

  1. Reset the ancilla to |0⟩ and apply a Hadamard, giving |+⟩.
  2. Apply a CNOT between ancilla and data qubit. Through phase kickback, the "fine" component of the data leaves the ancilla in |+⟩ and the "flipped" component leaves it in |−⟩.
  3. Apply a Hadamard and measure the ancilla, giving 0 or 1.
  4. The measurement projects the qubit onto |+⟩ or |−⟩, so the accumulated phase is converted into a discrete stabilizer outcome.

The measured value is the syndrome s. A detection event is a change in the syndrome between consecutive rounds, dr = sr ⊕ sr−1. Detection events are the only information the decoder receives.

1.0×

Recovering the phase from many shots

A shot is one full run of the experiment (8 rounds here). A single shot gives only one bit per round. Over many shots, the fraction f of shots that fire in round r estimates sin²(θ/2), so the phase accumulated in that round is θ = 2·arcsin√f. The sign of θ cannot be recovered, and the estimate becomes unreliable as f approaches 0.5.

Key point: the stabilizer measurement converts a continuous phase error into a discrete outcome. Statistics over many shots recover the phase per round.
Step 4

Measurement frequency and detection latency

Each measurement resets the phase error to zero, so the qubit only carries the phase accumulated since its last check. Since the flip probability scales as θ², dividing the same total phase over more checks reduces the overall flip probability. This is the quantum Zeno effect.

Regime

For slow noise (τc ≫ T), more frequent checks delay detection. For fast noise (τc ≪ T), latency depends only weakly on T. The transition between these regimes shows where the noise memory becomes visible in the syndrome data.

Key point: detection latency depends on both the noise and the cycle time; the relevant comparison is T versus τc.

The four data qubits are treated independently. This gives the correct detection timing; in a real surface code they share an entangled state.

With the default settings, Q1 is hit at 200 ns, after its CNOT ends at 180 ns, and is detected in round 2. The same error on Q2–Q4 is detected in round 1. This gate-scheduling effect can make simultaneous errors appear in different rounds, which a decoder may misread as noise propagating between qubits.

Key point: latency = wait until the qubit's next CNOT + readout time. The detection round depends on the error time, the qubit's position in the CNOT order, and the noise strength.
Step 6

Decoding with minimum-weight perfect matching

The distance-3 surface code encodes one logical qubit in nine data qubits (Q1–Q9). The purple X-type stabilizers detect Z errors. The decoder sees only which stabilizers fired and must infer which qubits flipped.

In minimum-weight perfect matching (MWPM), each data qubit is an edge between the stabilizers it belongs to (or between a stabilizer and the code boundary). Fired stabilizers are paired with each other or with a boundary so that the total number of edges is minimal, which is the most likely explanation when errors are rare. The correction is tracked in software (the Pauli frame).

With two errors, MWPM chooses the lower-weight explanation, and the combined error and correction form a chain across the code: a logical error. Distance 3 guarantees correction of one error only. Statistics: compares the logical error rate with the physical error rate p.

This demo uses a single, perfect measurement round. In practice, decoding is done over space and time: detection events from all rounds are matched, with additional edges for measurement errors and scheduling delays. Standard MWPM assumes independent errors; incorporating noise correlations into the edge weights is the goal of this research.

Key point: MWPM selects the minimum-weight explanation of the detection events. It fails when the actual error is less likely than another explanation.
Step 7

Summary and research question

The steps above form one chain. The research question is how much of the noise memory survives each link, and whether a decoder can use it.

Three memory time scales

Time scaleMeaning
τ_environment (τc)Correlation time of the noise
τ_qubitHow long the noise history remains in the qubit phase
τ_syndromeCorrelation time remaining in the detection events after repeated measurement

The decoder only has access to τ_syndrome, so the first task is to measure how τc maps to τ_syndrome.

Confounding effects

Gate scheduling, measurement errors, gradual phase build-up, one error triggering two stabilizers, and error cancellation can all produce apparent correlations in the detection record. The simulation therefore stores the true noise history separately from the decoder-visible data, so every inference can be checked against ground truth.

Research question: how much of the noise memory survives through the qubit and the stabilizer circuit into the syndrome record, and can a decoder use it to reduce logical errors?
